# Skill evals — run workspace

Where skill eval **runs** live. The eval **definitions** do not live here — they
ship inside each skill so they travel with it:

```
.claude/skills/<skill>/evals/
  eval.md                    ← how to run + the task prompt + grading rules (committed)
  expected-findings.json     ← answer key: findings (file, lines, rule) + must_not_flag (committed)
  fixtures/                  ← hermetic code tree the task points at (committed)

.claude/skill-evals/<skill>/ ← this folder: everything generated by a run
  iteration-N/               ← git-ignored (see root .gitignore)
    eval-<id>-<name>/
      with_skill/run-1/{outputs/, grading.json, timing.json}
      without_skill/run-1/{…}
    benchmark.json · benchmark.md · review.html
```

## Fixture rules

- **Hermetic.** The fixture tree contains every file the reviewer needs
  (container, ports, adapters, schema, contracts) and typechecks on its own —
  it never depends on the real `server/src`, so evals do not drift when the repo
  changes and runs are not distracted by unrelated mismatches.
- **Deliberately broken, silently.** No comment names or hints at a planted
  problem; `expected-findings.json` is the only answer key.
- Context files that are correct on purpose (composition root, adapters,
  repositories) are listed in `must_not_flag` — they measure false positives.
- Never compiled with the app, imported or reviewed: `server/`/`client/`
  tsconfigs don't reach `.claude/`, and `pr-self-review`'s `collect-diff.sh`
  excludes `.claude/skills/*/evals/fixtures/`.

Typecheck a fixture tree against the server's dependencies with a throwaway
tsconfig (`moduleResolution: bundler`, `paths: {"*": ["<repo>/server/node_modules/*"]}`,
`include: ["<fixtures>/**/*.ts"]`) and `server/node_modules/.bin/tsc -p`.

## Running

Today: manually through the `skill-creator` skill, with this folder as its
workspace, following the skill's `evals/eval.md` (copy `fixtures/` out of the
skill dir, run with and without the skill, grade against
`expected-findings.json`). Aggregate with
`skill-creator/scripts/aggregate_benchmark.py` and view with
`eval-viewer/generate_review.py` (needs Python ≥ 3.10 — `uv run --python 3.12`).

CI (not wired yet): for every `.claude/skills/*/evals/eval.md`, copy `fixtures/`
to a temp dir, run `claude -p` with the Task section, match the produced
`file:line` findings against `expected-findings.json` deterministically
(file + `line_tolerance`), use a grader model only to confirm descriptions, and
fail when recall < `pass.min_recall` or false positives > `pass.max_false_positives`.
