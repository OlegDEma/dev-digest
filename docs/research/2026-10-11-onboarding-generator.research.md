## R2 — investigator: deterministic facts for stack, structure, routes, scripts

**Answer.**
- **Routes:** `extractEndpoints` (`server/src/adapters/codeindex/extract.ts:182-193`) is a line-by-line regex heuristic: receivers `app|router|fastify|server|api` + verbs get/post/put/patch/delete/options/head with a quoted path, or `method: 'X' … url: '…'` on one line. Output `"METHOD /path"`. Not recognised: Next.js `app/**/route.ts` handlers, `pages/api`, NestJS decorators, Hono/Koa with other receiver names, multi-line chains, `register(..., { prefix })` prefixes, file-system routes. A client-side `api.get('/x')` call matches and is recorded as an endpoint (read from the regex, untested). `file_facts` (`server/src/db/schema/repo-intel.ts:75-88`) stores only `endpoints` and `crons` per file; rows written only when non-empty (`pipeline/full.ts:186-190`, `incremental.ts:193`).
- **Walked files:** only `.ts .tsx .js .jsx .mjs .cjs` (`constants.ts:14`, `walk.ts:100-101`); `.json/.yml/lockfiles/Dockerfiles/.md` never walked. Excluded dirs `node_modules dist build coverage .next out vendor .git` (`constants.ts:17-26`). Cap keeps the first 5000 **alphabetical** paths after `out.sort()` (`walk.ts:65-67`).
- **Scripts, lockfiles, compose, Next.js routes:** nothing parses them. `package.json` is read verbatim as a raw text sample only by conventions (`conventions/constants.ts:13-30`, `conventions/service.ts:212,218`). Grep of `server/src`, `reviewer-core/src`, `mcp/src` for lockfile/compose/`"scripts"`/`next.config`/`page.tsx` — no matches. No framework, package-manager, language-mix or script detection exists.
- **Walk stats:** `WalkStats { totalCandidates, skippedTooLarge, bounded }` (`walk.ts:36-43,57,103,113`) is spread into `repo_index_state.stats` jsonb on full index (`full.ts:102-103,254-255`). `bounded` is NOT added to `filesSkipped`. Incremental refresh overwrites `stats` without walk stats (`incremental.ts:245-263`), so `totalCandidates`/`bounded` are lost after the first incremental. `tryGetIndexState` projects only `durationMs`, `reason`, `degradedReason` from `stats` (`repository.ts:205-233`); `GET /repos/:id/index-state` returns `repoId, status, filesIndexed, filesSkipped, durationMs, reason, lastIndexedSha, indexerVersion, updatedAt, degraded?, degradedReason?` — no `totalCandidates`/`bounded`. No row → synthetic `degraded`/`no_data` (`service.ts:190-205`). Route has no response schema and returns camelCase (`routes.ts:35`) — breaks the snake_case contract rule; `IndexState` is hand-defined three times (server `types.ts:42-50`, `repository.ts:219-233`, client `client/src/lib/hooks/repo-intel.ts:14-24`), not in `@devdigest/shared`.
- **Callers:** `getTopFilesByRank` — only via `getConventionSamples` (`service.ts:662`; `conventions/service.ts:200-203`). `getCriticalPaths` — no production caller; only `server/test/repo-intel-facade-degraded.test.ts:95-96` (both resolve `[]` when degraded). ## R3 — researcher: LLM call and cost recording; structured-output retries

**Answer.** No generic per-call table. Intent persists tokens/cost on one row per PR (`pr_intent`: `tokensIn`, `tokensOut`, `costUsd`, `model`, `computedAt` — `server/src/db/schema/reviews.ts:57,70-73`; upserted by `prId`, so latest only — `intent/service.ts:200-212`, `intent.repo.ts:15-30`). Conventions persists no cost; returns `cost_usd` in the HTTP response only (`conventions/service.ts:179-187`), no tokens.

- **Log lines:** `prompt.assembled` (pino info, content-free, one per logical call, emitted before the call) — fields `event, v, call_id, feature (review|intent|conventions), provider, model, mode, run_id, run_ids, pr_id, repo_id, agent, session_id, chunk, sections[], totals{chars,tokens,sections}` (`server/src/platform/prompt-log.ts:111-128,196-206`). Emitted only when prompt-log mode ≠ `off`; **default is `off`** (`:202,221`). No output tokens, no cost; token counts from the local tokenizer. Intent pre-call RunLogger line `Intent classifier → provider/model · prompt ≈N tok … call_id=<uuid>` (`intent/service.ts:160-178`); post-call `Intent derived — … tokens IN/OUT, $0.0000` with data `model, tokens_in, tokens_out, cost_usd, diff_tokens_saved` (`:214-225`). No log line carries a call count or `attempts`.
- **Retries, layer 1 (schema):** `reviewer-core/src/llm/structured.ts:54-84` only parses and builds a reprompt; the loop lives in each provider's `completeStructured` — OpenRouter `reviewer-core/src/llm/openrouter.ts:61,68,122-125`, Anthropic `server/src/adapters/llm/anthropic.ts:92,99,140-145`, OpenAI `server/src/adapters/llm/openai.ts:90,96,128-129`: `maxRetries = req.maxRetries ?? 2`, attempts `1..maxRetries+1`, throws after last. Intent/conventions don't pass `maxRetries` → up to 3 requests. Tokens and cost accumulate across attempts (`openrouter.ts:104-108`). `StructuredResult.attempts` exists (`server/src/vendor/shared/adapters.ts:81`) but nothing outside adapters/mocks reads it. `maxRetries: 0` → exactly one request on schema failure (inferred from loop bounds).
- **Retries, layer 2 (transient):** OpenRouter SDK client `maxRetries: 2`, timeout 90 s (`openrouter.ts:51-56`) — invisible to `attempts`; worst case 3×3=9 HTTP requests (inferred). Anthropic/OpenAI wrap each attempt in `withRetry(withTimeout(...))`, default `retries = 3` on 429/5xx/ECONNRESET/ETIMEDOUT/ENOTFOUND (`server/src/platform/resilience.ts:35-60`); SDK default `maxRetries` not verified.
- **Cost source:** OpenRouter uses real `usage.cost` (requests `usage: { include: true }`), summed across attempts, falling back to `PriceBook.estimate` (`openrouter.ts:93,107-108,117`; `container.ts:208-211`). Anthropic/OpenAI use static `estimateCost` (`anthropic.ts:135`, `openai.ts:122`). `costUsd` is `null` for unknown models (`price-book.ts:34-38`).

**Not found:** a generic `llm_calls` table; any log with `attempts`; actual HTTP request count per run (needs a running system or a counting mock).
